스캔 디렉토리

    앱 밖에서 삭제/이동된 파일의 라이브러리 항목을 제거합니다.

    자주 쓰는 경로의 즐겨찾기입니다 — 스캔 탭에서 자동완성·기본값으로 제안되고, 라이브러리에 아직 없는 파일도 이 경로 하위라면 이미지 표시가 허용됩니다. 등록하지 않은 경로도 스캔은 가능합니다. 등록을 해제해도 이미 스캔된 기록은 라이브러리에 남습니다 — 기록까지 지우려면 각 항목의 "기록 정리"를 사용하세요.

    기록 정리

    
      
    
        파일은 삭제하지 않고 라이브러리 기록만 정리합니다. 기록은 아카이브로
        옮겨져 복구할 수 있고, 같은 경로를 다시 스캔하면 태그·품질이 재계산 없이
        되살아납니다.
      
    
    
    

    
    
      
    아카이브
    
      
    
        
        
        
        
        
        
        
      
    
      
      
      
      
        보존 기간이 지난 항목은 자동으로 정리됩니다(0 = 수동으로만 정리).
        전체 삭제는 되돌릴 수 없습니다.

          품질 분석
          
      
          
        
        
        
      
          
      
          
        
      
          
      
          
        블러/노출/대비/저해상도 휴리스틱과 생성 설정(낮은 Steps, 극단적 CFG) 기반으로
        0–100 점수와 이슈를 부여합니다. 신체 파손 검출(ML)은 로드맵에 있습니다.
      
          
    
          

    
          
      
          파일 정리
          
      
          
        
        
        
        
      
          
      
          
        라이브러리 탭의 현재 필터(검색/도구/그룹/품질 등)에 해당하는 파일을
        템플릿 경로로 이동합니다. 변수: {model} {tool} {date} {group} {sampler}
      
          
      
          
    
          

    
          
      
          인증

          설정·스캔·파일 작업 등 경로/시스템 관련 기능은 관리자 전용입니다.
