# 사용자 가이드

## 개요

GenSight는 AI 생성 이미지(Stable Diffusion WebUI/Forge, ComfyUI, NovelAI 등)에
내장된 생성 메타데이터 — 프롬프트, 네거티브 프롬프트, 샘플러, CFG, 시드, 모델 —
를 추출해 보여주고, 게시판에 붙여넣기 좋은 형식으로 복사할 수 있는 로컬 도구입니다.

## 1. 디렉토리 스캔

**스캔** 탭에서:

1. 디렉토리 경로를 **직접 입력**하거나, 설정에 등록된 경로를 선택합니다.
   (등록하지 않은 경로도 즉시 스캔할 수 있습니다.)
2. *하위 폴더 포함* 여부와 **추출 워커 수**를 지정합니다.
   - 이미지가 수만 장인 디렉토리라면 워커 수를 높여 속도를 올리거나,
     다른 작업에 영향이 없도록 낮출 수 있습니다.
3. **스캔 시작**을 누르면 백그라운드 작업으로 실행되며,
   진행률 바에서 상태를 확인하고 언제든 **취소**할 수 있습니다.

여러 스캔을 동시에 실행할 수 있으며, 동시 실행 개수는
설정의 *동시 작업 수*로 제한됩니다.

## 2. 단일 이미지 분석 (드래그 & 드롭)

스캔 탭의 **단일 이미지 분석** 영역에 이미지를 끌어다 놓거나
클릭해서 파일을 선택하면, 즉시 분석 결과가 팝업으로 표시됩니다.
업로드된 파일은 `data/uploads/`에 보관됩니다.

## 3. 결과 보기 (라이브러리)

스캔 결과는 모두 영구 라이브러리(SQLite)에 저장되며 **라이브러리** 탭에서 봅니다.
스캔 탭의 *결과 보기* 버튼은 라이브러리를 해당 디렉토리로 필터해서 엽니다
(상단의 📁 칩을 클릭하면 필터 해제).

- 프롬프트 / 파일명 / 모델 / 태그 검색, 도구·평점·그룹·품질 필터, 정렬.
- **JSON ⬇ / CSV ⬇**: 현재 필터가 적용된 라이브러리 전체를 내보냅니다.
- 카드를 클릭하면 상세 팝업이 열립니다.

### 상세 팝업

- **⇅ / ⇆ 버튼**: 이미지와 메타데이터의 배치를 좌우 ↔ 상하로 전환합니다.
  (선택은 브라우저에 저장됩니다.)
- **복사 형식**: 보기(읽기 좋은 형식) / JSON / Markdown / BBCode / **아카라이브** / 프롬프트만
  - **아카라이브**: 위지윅 에디터에 그대로 붙여넣도록 HTML로 복사합니다
    (프롬프트 박스 + 설정 표, 인라인 스타일만 사용). Markdown·BBCode를
    해석하지 않는 에디터에서 쓰세요. 텍스트만 지원하는 곳에는 평문으로
    떨어집니다.
- **이미지 포함**: 체크하면 썸네일 이미지까지 함께 클립보드에 복사되어,
  HTML 붙여넣기를 지원하는 게시판/에디터에 이미지+메타데이터가 함께 붙습니다.
  (브라우저가 이미지 클립보드를 지원하지 않으면 텍스트만 복사됩니다.)

### 내보내기

결과 탭 상단의 **JSON ⬇ / CSV ⬇** 버튼으로 현재 작업의 전체 결과를
파일로 내려받을 수 있습니다.

## 4. 설정

**설정** 탭 — 설정값은 `data/settings.json`에, 계정과 라이브러리는
`data/gensight.db`에 저장됩니다.

| 항목 | 설명 |
|---|---|
| 스캔 디렉토리 | 자주 쓰는 경로 등록 (스캔 탭에서 자동완성으로 제공) |
| 스캔/추출/썸네일 워커 | 각 기능별 스레드 수 |
| 동시 작업 수 | 동시에 실행할 스캔 작업 개수 |
| GPU | ML 분석에 사용할 GPU 선택 및 GPU당 동시 작업 수 |
| 기록 정리 | 특정 경로의 라이브러리 기록만 정리 (파일은 그대로) |
| 아카이브 | 정리된 기록의 보관·복구·보존 기간 |
| 언어 | 우측 상단에서 한국어/English/日本語 즉시 전환 |

### 디렉토리 등록을 해제해도 기록은 남습니다

**스캔 디렉토리**는 즐겨찾기입니다 — 등록을 해제해도 이미 스캔된 이미지 기록은
라이브러리에 그대로 남습니다. 한 경로를 여러 번 스캔했을 수도 있고, 태그·품질
같은 비싼 분석 결과를 잃지 않아야 하기 때문입니다.

기록까지 지우려면 **기록 정리**를 쓰세요 (디렉토리 항목의 `기록 정리` 버튼 또는
설정의 기록 정리 카드):

1. 경로와 범위를 고르고 **미리보기** — 대상 건수, 파일이 실제로 있는지, 함께
   사라질 태그·품질·그룹·평점 건수, 겹치는 감시/스캔 경고를 보여줍니다.
2. 확인 후 **정리 실행**. **파일은 삭제되지 않습니다** — 기록만 아카이브로
   옮겨집니다.
3. 잘못 지웠다면 **아카이브** 카드에서 `복구`. 같은 경로를 다시 스캔해도
   태그·품질이 재계산 없이 되살아납니다.

아카이브는 기본 30일 후 자동 정리되며(설정에서 변경, `0`이면 수동만), 카드에서
직접 `만료분 정리`·`전체 삭제`를 할 수도 있습니다. 전체 삭제는 되돌릴 수 없습니다.

## 5. 사용자 역할 (인증 활성화 시)

설정 → 인증에서 관리자 계정을 만들고, **사용자 관리**에서 계정을 추가합니다.

| | 관리자 | 일반 사용자 |
|---|---|---|
| 라이브러리 조회/평점/즐겨찾기, 통계 | ✅ | ✅ |
| 단일 이미지 분석 (드래그&드롭) | ✅ | ✅ |
| 설정 열람/변경, 스캔, 작업 목록 | ✅ | ❌ (403) |
| 감시/그룹/휴지통/파일 정리/품질·태깅 실행 | ✅ | ❌ (403) |
| 기록 정리·아카이브 (`/api/admin/*`) | ✅ | ❌ (403) |

일반 사용자에게는 설정 탭·스캔 카드가 UI에서 숨겨지며, 서버 측에서도
경로를 입력받거나 시스템 상태를 바꾸는 모든 API가 차단됩니다 —
인스턴스를 외부에 공개할 때 일반 계정만 배포하세요.

## 지원 포맷

| 생성 도구 | 인식 방법 |
|---|---|
| A1111 / Forge / SD.Next | PNG `parameters` 청크, JPEG/WebP EXIF |
| ComfyUI | PNG `prompt`(노드 그래프) — 그래프를 추적해 프롬프트/설정 복원 |
| NovelAI | PNG `Comment` JSON |
| 메타데이터 없음 | 크기 등 기본 정보만 표시 |

지원 확장자: `.png` `.jpg` `.jpeg` `.webp` `.avif` `.bmp` `.tiff`
